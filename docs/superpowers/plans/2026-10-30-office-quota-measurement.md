# Office quota measurement implementation plan

**Goal:** Measure every Head wake and shared-account quota window without inference or funded-path work.
**Spec:** Office v2 persistent seats design section 3 budget and section 7 proof; Alpha queue 2026-10-30; Beta interface ACK.
**Ownership:** Delta: `sniper/office/quota_measurement.py`, `scripts/office_quota_snapshot.py`, dedicated tests. Beta: seat host/tools, trusted identity and config, verified SDK usage scope. Gamma: proof interpretation. No funded imports, production DB/schema writes, model calls, .env changes or activation.

1. Write failing SQLite fixture tests for wake idempotence, conflicting identity, duplicate result, valid zero, four required counters, unknown scope/cap, timeout, over-cap, UTC day, future clock and retention. Run with `-n 2`, confirm RED.
2. Add a small explicit `ensure_schema(conn)` bootstrap (host calls it), append-only wake/account observation tables and time/actor indexes. Reuse Office `write_transaction`. Store only whitelisted metadata; never credentials, prompts or raw provider responses.
3. Implement `record_wake(conn, *, epoch_id, actor_id, generation, incarnation, session_id, wake_id, account_alias, outcome, counters, result_id, started_at, ended_at, per_wake_max=None, usage_scope='unknown', absolute_ceiling=200000, calibration=False, sdk_version=None)`. Four raw counters are input/output/cache-read/cache-create; counted usage excludes cache-read (ruled section A item 11). SDK Result usage must be verified per-wake; monotonic counts alone establish nothing. All outcomes are retained; known usage stays known even on failure. Calibration is labelled; absolute ceiling and calibrated cap are separate, breaches stay known and flagged. Unknown scope/counters/policy keeps usage unknown. Exact wake replay is idempotent; conflicting replay refuses. Reused result across wakes becomes unknown.
4. Implement `wake_budget(conn, *, actor_id, now, limit)` as one indexed bounded day read. UTC completion day, known zero only on an empty valid day, unknown receipt/cap/clock or read cap parks the seat. Return `state`, `used`, `limit`, `exhausted`, typed reason. During the 24h proof the host reports daily budget without enforcing it (ruled item 11); the host enforces hourly wake limits and calibration coverage. The host owns admission serialization and per-wake hard output bounds; this is not a reservation system.
5. Implement account snapshot normalization and idempotent storage; Claude five-hour/seven-day and Codex named primary/secondary windows stay separate. Null is unknown, never unlimited. Percentages never become token caps. Provider account IDs and credit-reset identities are omitted.
6. A host-only one-shot script polls Claude OAuth usage or an ephemeral Codex stdio account/rateLimits/read without any model turn, renewal request, reset consumption or funded provider traffic. Explicit DB path and account alias; bootstrap/write only that selected measurement DB. Bounded network timeout/body and subprocess cleanup. Poll failures persist typed unknown snapshots. Test injected transport responses and cleanup.
7. Retention: 30 days, bounded oldest-first deletion of standalone measurement rows (no evidence-chain deletion), invoked explicitly off wake path. Keep source snapshots private; no new cron. Run focused tests and diff/schema checks, commit owned files, Gamma/Zeta review; Alpha integrates/activates.

Not handled: absolute token/day subscription capacity, attribution of concurrent crew quota consumption to Head, unobserved crashed wakes, SDK scope verification, seat incarnation fencing, concurrent wake admission, paid API usage, or a five-seat fit verdict. SDK version, calibration flag and absolute ceiling are recorded. `account_guard` implements the ruled 50% five-hour / 80% weekly USED thresholds, with explicit freshness and unknown parking; the host owns hourly count and proof-phase daily-gate policy. Host must record failed/crashed wakes and park unknown; Beta owns those calls. Source rollback stops calling this module and leaves the standalone tables intact.
