# Curve-fullness test: pre-registration (Gamma, 2026-10-23)

Frozen BEFORE any fullness-binned outcome is computed. Operator question (via Alpha): do desk PASS candidates, and JUDGE ENTERs, with high curve fullness at the decision moment lose money once graded on the REAL outcome (through graduation onto the PumpSwap pool), not the last curve spot? Measurement only; any live change (a 'graduation imminent' JUDGE fact or a hard skip) = operator + new cohort. Script: `scripts/research/desk_curve_fullness.py` (read-only). Builds on Part 1 labels (`docs/superpowers/specs/2026-10-23-desk-decision-quality-preregistration.md`) and the graduated stratum F0 (`docs/audits/2026-10-23-graduated-stratum-f0.md`).

## Definitions (fixed)
- **Fullness F** = `real_quote` of the last curve swap at or before E8 (= PASS + 8 s, the achievable entry time) divided by 85.0 SOL (the observed graduation threshold: last curve prints are 85.01 SOL). A ticket with no curve swap in the 60 s before E8 is `no_curve_state` (excluded, counted).
- **Bins (frozen):** B1 F < 0.50; B2 0.50 <= F < 0.65; B3 0.65 <= F < 0.75; B4 0.75 <= F < 0.85; B5 F >= 0.85. **Candidate rule (frozen): skip when F >= 0.75** (B4 + B5). No other cut is declared; X is read only from the per-bin table, not fitted.
- **Population:** the Part 1 PASS-pool tickets on UTC 2026-10-23 with PASS after the PumpSwap capture start (06:57:02Z). 10-22 tickets have NO pool tape, so they cannot be graded through graduation: excluded as `no_pool_tape`, counted, never graded on the curve spot. Both days stay in the Part 1 table as before.
- **Grading (the real outcome):** entry at the curve spot at E8; desk rails 30/18/12 (or the vet verdict's own) on the SPOT path (no fees, no impact, same convention as Part 1); horizon 300 s after E8. While the coin is on the curve the path is the curve tape. If the curve ends (a swap with real_quote >= 84 SOL, or no later curve swap) the path continues on the coin's CANONICAL pool (`memecoin_slot_graduation.canonical_pool(mint)`) from `swaps_ps` using only swaps with proven post-trade reserves (price = post_quote/post_base in SOL/token). The migration step is real and kept (pool price vs last curve print is not smoothed). **Censor, never fill:** a graduated ticket is `censored` if the first priced pool swap is more than 30 s after the last curve print, or a priced-pool gap of more than 60 s occurs before the rails resolve, or `gaps_ps` rows (decode_loss / virtual_quote_unproven / restart) cover the window and leave no priced swap in the next 30 s; the last curve spot is never used after graduation. Censored counts are reported per bin and the table is shown with and without them as `lower/upper` only where they could change the sign.
- **Reads per bin (and for B4+B5 vs B1-B3):** n, mean rail return with a 90% mint-cluster bootstrap CI (2,000 draws, seed 23), win rate, median, P(graduates within the hold), mean rail return of graduated vs non-graduated rows, censored count. **Inside B4+B5:** JUDGE ENTER vs SKIP vs not-called (n and mean). Difference reported: (B4+B5) minus (B1-B3), CI.
- **Out-of-sample:** the rule and bins above are frozen now. The identical script is run once on UTC 2026-10-24 (pool tape present all day) after the day closes. No bin, threshold or definition changes between the two reads.

## Decision rules (frozen)
1. A 'graduation imminent' JUDGE FACT is supported only if, in BOTH the 10-23 read and the 10-24 read, the (B4+B5) mean rail return is lower than the (B1-B3) mean and the difference CI excludes 0 in at least one read with the same sign in the other, with >= 25 graded non-censored rows in B4+B5 in each read.
2. A HARD SKIP at F >= 0.75 is supported only if, in addition, the (B4+B5) mean rail return is negative with a 90% CI whose upper bound is below 0 in the 10-24 read AND the upper-bound censoring bracket does not change the sign.
3. Anything else: 'not supported at this n', stated with the numbers; no recommendation. The fullness effect on JUDGE ENTERs is reported as description, never as a rule.
4. Biases named: spot grading excludes fees/impact on both legs (the pool leg is worse than shown); graduation migration step is included; the PS tape covers one day; clusters are few in high bins; the 5-minute hold is the desk's rails horizon, not an optimum; fullness is measured at E8, JUDGE decided ~2 s earlier.
