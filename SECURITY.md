# Security

Do not include credentials, wallet secrets, session tokens, or unredacted production traces in public issues or pull requests.

For a sensitive report, use the repository's private vulnerability reporting feature when available. If it is unavailable, open an issue containing only a request for a private contact channel; do not publish the sensitive material.

This is a source-review snapshot, not a security certification or a supported deployment distribution. Running execution code with real funds requires independent review and deliberate configuration.
